🚀 DEPLOY AUTOMÁTICO (3 PASSOS)
═══════════════════════════════════════════════════════════════════

PASSO 1: Enviar projeto para VPS
─────────────────────────────────
No seu PC (PowerShell):
  
  .\enviar-para-vps.ps1

  ↳ Digite o IP da VPS
  ↳ Aguarde o envio


PASSO 2: Instalar Docker na VPS
────────────────────────────────
Conecte na VPS via SSH:

  ssh root@SEU_IP_VPS

Execute:

  cd /opt/qibot
  chmod +x install-docker-vps.sh
  ./install-docker-vps.sh


PASSO 3: Fazer Deploy
──────────────────────
Ainda na VPS:

  ./deploy-vps.sh

  ↳ Aguarde a construção dos containers
  ↳ Acesse: http://SEU_IP_VPS:8081

═══════════════════════════════════════════════════════════════════
🔧 DEPLOY MANUAL (ALTERNATIVA)
═══════════════════════════════════════════════════════════════════

1. Conectar na VPS:
   ssh root@SEU_IP

2. Clonar repositório:
   cd /opt
   git clone https://github.com/refleeexzz/chatbot-qitelecom.git qibot
   cd qibot

3. Configurar .env:
   nano .env
   (Cole suas configurações e salve: Ctrl+O, Enter, Ctrl+X)

4. Subir containers:
   docker-compose up -d --build

5. Ver logs:
   docker-compose logs -f

═══════════════════════════════════════════════════════════════════
🌐 CONFIGURAR DOMÍNIO (OPCIONAL)
═══════════════════════════════════════════════════════════════════

1. Instalar Nginx:
   apt install -y nginx certbot python3-certbot-nginx

2. Configurar proxy reverso:
   nano /etc/nginx/sites-available/qibot

   Cole:
   ────────────────────────────────────
   server {
       listen 80;
       server_name seu-dominio.com;
       
       location / {
           proxy_pass http://localhost:8081;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }
   ────────────────────────────────────

3. Ativar configuração:
   ln -s /etc/nginx/sites-available/qibot /etc/nginx/sites-enabled/
   nginx -t
   systemctl restart nginx

4. Configurar HTTPS:
   certbot --nginx -d seu-dominio.com

🆘 PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════════

Container não inicia:
  → docker-compose logs qibot
  → Verifique .env e variáveis

Porta em uso:
  → netstat -tulpn | grep 8081
  → Mate o processo ou use outra porta

Webhook não funciona:
  → Verifique se porta 8081 está liberada
  → Use HTTPS se possível (Meta prefere)

Erro de memória:
  → Verifique: docker stats
  → Aumente memória da VPS se necessário
